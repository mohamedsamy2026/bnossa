# b Nossa — Crochet with love

React + Vite + Tailwind CSS 3 + React Router + Swiper

## التشغيل
    npm install
    npm run dev      # للتطوير
    npm run build    # للنشر

## أين أغيّر البيانات؟
- `src/config/site.js`  → رقم الواتساب، رقم التليفون (منفصل)، العملة، روابط السوشيال (فاضية)
- `src/data/products.js` → المنتجات والتصنيفات (الصور والأسماء والأسعار مؤقتة)
- `src/config/translations.js` → كل النصوص بالعربي والفرنساوي
- اللوجو: `src/assets/logo-plate.png` (خلفية شفافة)
